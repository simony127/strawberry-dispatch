# 苺乳手札

可在自己電腦開啟、自己改內容的草莓牛奶品飲網站。

## 怎麼看

1. 下載整個 `ichigo-techou` 資料夾
2. 用瀏覽器打開 `index.html`
3. 右上角按「編輯手札」就能新增、修改、刪除樣本

照片請放進 `images/`，然後在表單「照片路徑」填 `images/檔名.jpg`。

## 資料存在哪

改過的內容存在瀏覽器的 localStorage。  
換電腦或清快取會不見，所以改完請按「匯出手札 JSON」備份。

匯入 JSON 可以還原。  
「還原預設兩筆」會回到桑格利亞與十字牌這兩份報告。

## 之後若要放到網上

可以把整個資料夾丟到 GitHub Pages、Cloudflare Pages 或任何靜態空間。  
線上版的編輯仍然只存在「你正在用的那個瀏覽器」，不會自動同步給所有訪客。  
若要讓網站上的資料固定給大家看，把匯出的 JSON 內容貼回 `data.js` 裡的 `ICHIGO_DEFAULTS` 即可。
